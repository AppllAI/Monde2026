# Monde 2026 pour iPad (Swift Playgrounds)

1. Touchez **Monde2026-iPad.zip** ci-dessus, puis **Download** (Télécharger).
2. Dans l'app **Fichiers** > Téléchargements, touchez le zip pour le décompresser.
3. Touchez **Monde2026** (le dossier .swiftpm) : il s'ouvre dans Swift Playgrounds.
4. Appuyez sur ▶︎ pour lancer le jeu.
