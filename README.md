# Monde 2026

Jeu de grande stratégie sur iPhone et iPad : le monde au 1er janvier 2026, 154 pays, ~600 régions.

- `Monde2026/` : tout le code Swift (SwiftUI + MapKit)
- `project.yml` : description du projet Xcode (générée par XcodeGen)
- `.github/workflows/build.yml` : compilation automatique sur un Mac de GitHub à chaque modification

Version 0.9 : guerre région par région.
